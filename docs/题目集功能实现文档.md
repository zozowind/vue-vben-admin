# 题目集功能实现文档

## 功能概述

本文档描述了ParseQ-UI项目中题目集（练习卷）功能的完整实现，包括题目选择、卷面预览、打印等功能。

## 功能特性

### 核心功能
1. **题目集管理**
   - 创建题目集
   - 编辑题目集信息
   - 删除题目集
   - 查看题目集详情

2. **题目选择与组织**
   - 从题目库中选择题目
   - 支持多条件筛选（学科、难度、年级等）
   - 题目搜索功能
   - 题目排序管理

3. **试卷预览与打印**
   - 实时预览试卷效果
   - 支持多种纸张规格（A4、A3、Letter）
   - 可调节字体大小
   - 答案和解析显示控制
   - 标准试卷格式输出
   - 一键打印功能

4. **导出功能**
   - PDF导出（规划中）
   - Word文档导出（规划中）
   - 图片导出（规划中）

## 技术架构

## API接口设计

### 题目集相关接口

```typescript
// 创建题目集
POST /api/v1/question-sets
{
  "name": "题目集名称",
  "description": "描述",
  "set_type": "practice",
  "settings": {
    "duration": 60,
    "totalScore": 100,
    "showAnswer": false
  }
}

// 获取题目集列表
GET /api/v1/question-sets?page=1&page_size=20&status=active

// 获取题目集详情
GET /api/v1/question-sets/{id}

// 更新题目集
PUT /api/v1/question-sets/{id}

// 删除题目集
DELETE /api/v1/question-sets/{id}

// 获取题目集树形结构
GET /api/v1/question-sets/{id}/tree

// 获取题目集的题目列表
GET /api/v1/question-sets/{id}/questions

// 添加题目到题目集
POST /api/v1/question-sets/{id}/questions
{
  "question_id": "题目ID",
  "sort_order": 1
}

// 从题目集删除题目
DELETE /api/v1/question-sets/{id}/questions/{questionId}

// 更新题目顺序
PUT /api/v1/question-sets/{id}/questions/order
{
  "items": [
    {
      "id": 1,
      "question_id": "题目ID",
      "sort_order": 1
    }
  ]
}
```

```typescript
const selectedQuestions = computed(() => questionSetsStore.selectedQuestions);

const toggleQuestionSelection = (question: any) => {
  questionSetsStore.toggleQuestionSelection(question);
};

// 创建题目集
const handleCreate = async () => {
  // 1. 验证表单
  await formRef.value.validate();
  
  // 2. 创建题目集
  const questionSet = await questionSetsStore.createQuestionSet(formData.value);
  
  // 3. 批量添加题目
  const addPromises = selectedQuestions.value.map((question, index) => 
    questionSetsStore.addQuestionToSet(questionSet.id, question.id, index + 1)
  );
  await Promise.all(addPromises);
  
  // 4. 跳转到详情页
  router.push(`/question-sets/detail/${questionSet.id}`);
};
```

**打印功能实现:**
```typescript
const handlePrint = () => {
  // 隐藏不需要打印的元素
  const toolbar = document.querySelector('.no-print');
  if (toolbar) {
    (toolbar as HTMLElement).style.display = 'none';
  }
  
  // 设置打印样式
  const printStyles = `
    @media print {
      body * { visibility: hidden; }
      .paper, .paper * { visibility: visible; }
      .paper { 
        position: absolute; 
        left: 0; 
        top: 0; 
        width: 100% !important;
        max-width: none !important;
        margin: 0 !important;
        box-shadow: none !important;
      }
      .no-print { display: none !important; }
    }
    @page { 
      size: ${paperSize.value.toUpperCase()}; 
      margin: 1cm; 
    }
  `;
  
  // 应用样式并打印
  const styleSheet = document.createElement('style');
  styleSheet.textContent = printStyles;
  document.head.appendChild(styleSheet);
  
  window.print();
  
  // 恢复原状态
  setTimeout(() => {
    if (toolbar) {
      (toolbar as HTMLElement).style.display = '';
    }
    document.head.removeChild(styleSheet);
  }, 1000);
};
```

## 使用流程

### 创建题目集流程
1. 点击"创建题目集"按钮
2. 填写题目集基本信息（名称、描述、类型、设置）
3. 从题目库中选择题目
   - 支持搜索和筛选
   - 可预览题目内容
   - 实时显示已选题目数量
4. 点击"创建题目集"完成创建
5. 自动跳转到题目集详情页

### 预览和打印流程
1. 在题目集列表或详情页点击"预览"
2. 进入试卷预览页面
3. 调整预览设置
   - 字体大小
   - 纸张规格
   - 是否显示答案/解析
4. 点击"打印"进行打印
5. 可选择导出为其他格式

## 注意事项

### 开发注意事项
1. **错误处理**: 所有API调用都需要适当的错误处理
2. **加载状态**: 长时间操作需要显示加载指示器
3. **数据验证**: 前端和后端都需要进行数据验证
4. **权限控制**: 需要根据用户权限控制功能访问

### 性能优化
1. **分页加载**: 大量数据采用分页加载
2. **虚拟滚动**: 长列表使用虚拟滚动
3. **缓存策略**: 合理使用缓存减少API调用
4. **懒加载**: 组件和图片采用懒加载

### 用户体验
1. **操作反馈**: 及时的操作成功/失败反馈
2. **确认对话框**: 危险操作需要确认
3. **快捷键**: 支持常用快捷键操作
4. **无障碍**: 支持键盘导航和屏幕阅读器
